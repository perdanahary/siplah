# SIPLah Prototype - Fitur Banpem & Multi-PO Cart

Prototipe antarmuka SIPLah yang mengintegrasikan alur transaksi Bantuan Pemerintah (Banpem) dan pemisahan Multi-PO keranjang belanja berdasarkan sumber dana.

## ✨ Fitur Utama
- **Header SIPLah Telkom Modern**: Menampilkan navigasi, status login Satuan Pendidikan, pencarian, dan logo resmi (Kemendikdasmen & Danantara).
- **Halaman Keranjang Dinamis**:
  - Pemisahan keranjang / PO per penyedia dan sumber pendanaan (BOSP Reguler vs Banpem).
  - Indikator badge dan verifikasi dokumen persyaratan Banpem (Surat Dukungan SIASPRI, Buku Panduan Menulis Banpem, dll).
  - Lightbox interaktif untuk pratinjau dokumen pendukung.
  - Perhitungan estimasi total dan ringkasan checkout real-time.

## 🚀 Cara Menjalankan
Buka berkas `prototipe_keranjang_siplah_banpem.html` langsung di peramban web (browser) favorit Anda, atau jalankan menggunakan live server lokal.
